# Evidence for self-improvement across six studies

What counts as the next round? In Self-Refine it is another draft of the same answer. In Voyager it can be a new task in a fresh world. Each row follows one experiment from the artifact it changes to the conclusion its comparison supports. Percentages refer to the metric and task named in that row.

| Study and source | What changes? | What carries into the next round? | What is the comparison? | What does the result support? |
| --- | --- | --- | --- | --- |
| **Self-Refine** · [Table 2](https://arxiv.org/pdf/2303.17651v2#page=6) | A fixed language model critiques and revises a draft. | The next prompt includes earlier drafts and feedback for the same input. The model weights stay fixed. | On code optimization, ChatGPT revises with specific feedback, generic feedback, or no explicit feedback. | Specific feedback helped optimize 27.5% of programs, compared with 26.0% and 24.8% in the two controls. This measures improvement within a task. |
| **Reflexion** · [Table 3](https://arxiv.org/pdf/2303.11366v4#page=8) | A coding agent generates unit tests and writes a reflection on its attempt. | The next attempt at the same problem can use the written reflection. | On the 50 hardest HumanEval Rust problems, the authors compare GPT-4 with tests and reflection, tests alone, reflection alone, and the base model. | Pass@1 was 68%, 60%, 52%, and 60%, respectively. Reflection helped alongside test feedback in this subset. Reflection alone scored below the base model. |
| **Voyager** · [Table 2](https://arxiv.org/pdf/2305.16291v2#page=8) | A Minecraft agent adds executable skills to a library as it completes tasks. | A later task can retrieve the programs even after the inventory is cleared and the world is reset. | Voyager with and without the learned library tackles four unseen tasks, with three trials per task and a 50-prompt limit. | Both versions crafted a compass in all three trials. The library cut mean prompting iterations from 26 to 18, evidence that skills learned on earlier tasks can save work on a new one. |
| **STaR** · [Algorithm 1](https://arxiv.org/pdf/2203.14465v2#page=4) · [Table 1](https://arxiv.org/pdf/2203.14465v2#page=7) | GPT-J is fine-tuned on its own explanations that yield correct answers. For missed questions, it can try again with the correct answer supplied. | The trained model generates the next round’s examples. Each fine-tuning run starts from the original checkpoint. | On CommonsenseQA, compare full STaR, STaR without the answer-hinted retry, and GPT-J fine-tuned directly on answers. | Development accuracy was 72.5%, 68.8%, and 60.0%, respectively. Training on generated explanations helped here. The retry also increased training-set coverage, so its gain includes a change in the examples used. |
| **Meta-Rewarding Language Models** · [Table 3 and §3.4](https://arxiv.org/pdf/2407.19594v2#page=9) | The model ranks answers and also compares judgments. Both kinds of preference pairs train the same model. | The updated weights initialize the next training round and generate its answers and judgments. | At iteration four, compare Meta-Rewarding with length-controlled Self-Rewarding on GPT-4-chosen pairs of responses from the same seed model. | Judge agreement with GPT-4 on pairs without ties was 59.54% versus 53.12%. Judge training improved agreement with this reference. The authors report that gains in agreement with human rankings did not persist through later rounds. |
| **Darwin Gödel Machine** · [§4.3](https://arxiv.org/pdf/2505.22954v3#page=6) · [Appendix Table 1](https://arxiv.org/pdf/2505.22954v3#page=25) | A coding agent edits its own implementation, including tools it can use for future edits. | The archive retains agent code. A sampled descendant can make further edits using its inherited tools. | Compare the full system with a fixed initial agent making all edits, and with an evolving agent that can build only on the latest viable version. | On the paper’s staged SWE-bench evaluation, the best agents solved 50%, 39%, and 23%, respectively. Allowing the editor to evolve and retaining multiple lineages each helped the search produce a better solver. These endpoint scores do not measure the quality of each individual edit. |

For the definitions of task gain, retained gain, and improver gain, see [Scope & Terminology](../README.md#scope--terminology).
